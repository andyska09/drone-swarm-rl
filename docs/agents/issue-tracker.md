# Issue tracker: none

This is a personal project. It has no issue tracker, and the task specs take the place of issues.

## When a skill says "publish to the issue tracker"

Give the text to the user in the chat.

## When a skill says "fetch the relevant ticket"

Read the task spec, `research/notes/tasks/task_<name>.md`, and `research/notes/tasks/defaults.md` for what every task shares. If the user names no task, ask which one.
